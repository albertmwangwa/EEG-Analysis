EEG Analysis

Overview
This repository contains exploratory and modeling work for EEG (electroencephalography) signal analysis using Jupyter notebooks. The project focuses on reading EEG recordings from CSV files, preprocessing with MNE, visualizing signals and topographies, extracting features, and training/evaluating machine learning models (classification, regression, and ranking) with scikit-learn. Pretrained/persisted model artifacts are included in the models directory.

2) Create and activate a virtual environment (recommended)

Running the project
This project is notebook-centric. The primary entry points are the notebooks:
- EEG Analysis.ipynb (main)
- sample.ipynb (examples/scratch)

Steps:
1) Launch Jupyter:
- jupyter notebook
  or
- jupyter lab

2) Open EEG Analysis.ipynb and run cells sequentially. The notebook demonstrates:
- Loading EEG CSVs from the data folder
- Preprocessing and epoching with MNE
- Visualizations (time series, topomaps)
- Feature exploration/selection
- Model training/inference (classification, regression, ranking)
- Writing prediction outputs (CSV files under data/)

Notes on Unsupervised Stress-State Clustering
- Run EEG_CNN_LSTM_Autoencoder.ipynb to the end. The final section performs clustering on latent embeddings to infer states.
- The method uses silhouette-based selection for K (2..8) and reports GMM BIC as a reference.
- As a heuristic, clusters with higher mean reconstruction MAE may correspond to stress-like states; validate with domain context or labels if available.
